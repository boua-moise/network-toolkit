# Network Toolkit

Projet pédagogique destiné à comprendre les bases de la programmation réseau avec Python.

## Objectifs

- Comprendre les adresses IP
- Comprendre les ports TCP et UDP
- Étudier le modèle client-serveur
- Apprendre à utiliser les sockets Python
- Construire progressivement des outils réseau

## Structure

- `scanner.py` : futur scanner réseau pédagogique
- `README.md` : documentation du projet
- `.gitignore` : fichiers ignorés par Git

## Utilisation responsable

Les outils de ce projet doivent être utilisés uniquement sur mes propres machines,
sur un laboratoire personnel ou sur des systèmes pour lesquels j'ai reçu une
autorisation explicite.
